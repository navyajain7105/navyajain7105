## 🔬 Currently Researching

**Graph Coarsening for Fake News Detection**
Working on the UPFD dataset with PyTorch Geometric — comparing spectral coarsening methods (Variation, Algebraic Distance, Kron Reduction) against GCN / GraphSAGE / GAT models. Studied the ICLR 2021 paper *"Graph Coarsening with Neural Networks"* (GOREN) in depth and implemented the GK algorithm (Olshevskyi, Navarro & Segarra, 2025) as a base. Working toward a fully learnable, task-adaptive coarsening method, aiming to publish using the Cora dataset.
